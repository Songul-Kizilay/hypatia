
# Glossary

> "A shared language creates a shared understanding."

---

# Introduction

This glossary defines the terminology used throughout the Hypatia project.

Every document, module, and future contribution should use these terms consistently.

---

# Agent

An autonomous software component responsible for making decisions, planning actions, and coordinating tasks.

Example:

- Research Agent
- Memory Agent
- Career Agent

---

# Module

A functional component responsible for performing a specific capability.

Examples:

- Voice Module
- Vision Module
- Memory Module

Modules execute work.

Agents decide when and how to use them.

---

# Brain

The central orchestration system responsible for coordinating agents, reasoning, planning, and decision-making.

---

# Memory

The system responsible for storing, organizing, and retrieving information across conversations and long-term knowledge.

---

# Knowledge

Structured information that Hypatia can access, organize, and connect.

Knowledge may originate from:

- Documentation
- Books
- Research papers
- User notes
- Bug bounty writeups
- CVEs

---

# Research

The process of collecting, evaluating, organizing, and understanding information to answer questions or solve problems.

---

# Prompt

Instructions that guide the behavior of an AI model.

Prompts define how Hypatia reasons, communicates, or performs specialized tasks.

---

# Local-First

A design philosophy where computation is performed on the user's own device whenever practical.

Privacy and user control are prioritized over cloud dependency.

---

# Companion

The human-centered interaction layer of Hypatia.

Its goal is to support, teach, collaborate, and grow alongside the user.

---

# Orchestration

The coordination of multiple agents, modules, and services to achieve a common goal.

---

# Workflow

A structured sequence of actions performed to complete a task.

Example:

Research → Analysis → Summary → Memory

---

# Session

A continuous interaction between the user and Hypatia.

Sessions may contain conversations, tasks, research, and decisions.

---

# Context

Relevant information available to Hypatia during reasoning.

Context may include:

- Conversation history
- User preferences
- Current task
- Stored knowledge

---

# RAG (Retrieval-Augmented Generation)

A technique where retrieved knowledge is combined with language model reasoning to improve answer quality.

---

# Smart Home

Connected devices managed through Hypatia to improve automation, comfort, and safety.

---

# Robotics

Physical systems controlled or assisted by Hypatia through sensors, planning, and intelligent decision-making.

---

# Sentinel

The security monitoring subsystem responsible for detecting anomalies, monitoring devices, and improving digital safety.

---

# Vision

The capability to understand images, video, screens, and visual environments.

---

# Voice

The capability to understand speech and generate natural spoken communication.

---

# Principles

The permanent design values that guide development.

---

# Constitution

The highest-level rules that every future version of Hypatia must respect.

---

# Bible

The collection of foundational documents defining the identity, philosophy, architecture, and long-term direction of the project.

---

# Final Note

Whenever new terminology is introduced, it should be added to this glossary to maintain consistency throughout the project.
