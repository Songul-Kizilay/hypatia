# v0.1 — Personal Foundation

## Goal

Define and build the smallest useful local-first Hypatia experience: desktop, voice, memory, Ollama, and chat.

## Exit criteria

- Foundation documents and user-control boundaries have been reviewed.
- Desktop, voice, memory, Ollama, and chat specifications are agreed.
- Privacy, security, and approval expectations are documented.
- Implementation scope is explicitly agreed before coding begins.
